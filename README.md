# Expense Tracker (Command-Line)

A simple command-line Python app to help you **track your spending** by adding, viewing, deleting, and searching your transactions.

---

## Features

- Add new transactions (amount, category, description)
- View all transactions
- Delete unwanted transactions
- See total amount spent
- **Search** transactions by keyword (e.g., date, food, rent)

---

## ▶️ How to Run

1. Open terminal
2. Navigate to the project folder:
   ```bash
   cd expense_tracker
   python main.py
